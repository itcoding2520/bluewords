# BlueWords kids dashboard UI assets

A complete, editable SVG set based on the children's BlueWords dashboard mockup. Illustrations have transparent backgrounds and can be scaled without losing quality.

## Feature illustrations (`illustrations/`)
- `hero-book-mascot.svg` — smiling book mascot for the welcome hero
- `vocabulary-books.svg` — book stack for My vocabulary
- `flashcards-apple-cat.svg` — apple and cat flashcard pair
- `game-controller.svg` — Games card illustration
- `videos-penguin.svg` — penguin video player illustration
- `review-trophy.svg` — review achievement trophy
- `notifications-envelope.svg` — notification mail illustration
- `profile-jenny.svg` — profile portrait illustration
- `publish-globe-plane.svg` — publishing/world illustration
- `activity-streak-puppy.svg` — activity streak side mascot

## Icons (`icons/`)
Includes eight feature/navigation icons, three summary stat icons, and the smiling book mascot.

## Backgrounds (`backgrounds/`)
Includes a matching pastel card background for each feature block, three summary stat backgrounds, dashboard hero/page backgrounds, learning progress/activity panel backgrounds, and the active navigation background.

## Usage
Use illustrations and icons as `<img src="/assets/...svg" alt="" />`, import them as React components if SVGR is configured, or use backgrounds in CSS. Each SVG is standalone and editable. The feature art uses a matching bright pastel palette inspired by the mockup.
